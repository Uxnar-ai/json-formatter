# JSON 排版 jsonfmt · 粘进去就排好

> 粘贴 JSON 自动排版，支持压缩、查错定位到行列、键排序，全部在浏览器里算。

[English](README.en.md) | 中文

## 这是什么

接口返回的一大坨 JSON，粘进来直接变成能看的结构。

没有后端逻辑：页面只有一个空壳，解析、排版、着色全在浏览器里跑，所以内容不会发到任何地方。粘贴后 220ms 防抖自动排版，也可以按 `Ctrl/⌘ + Enter` 手动触发。

解析失败时，从 `JSON.parse` 的报错里取字符偏移，换算成行列告诉你是第几行第几列——比默认的 `Unexpected token` 有用得多。语法着色是单遍 token 扫描，字符串里的数字不会被当成数字上色。键排序是递归的，数组顺序保持不动。

## 功能

- 粘贴即排版，220ms 防抖，不用点按钮
- 解析失败报第几行第几列
- 缩进 2 / 4 空格 / Tab 可切
- 递归键排序，数组顺序不动
- 压成一行、复制结果、一键清空
- 深色/浅色自适应 + 手动切换，900px 以上双栏
